# 五月内容方案

## 总体方向
用“给普通一天留一点余地”串起三篇内容。沿用晨屿品牌简报的温和语气，每篇只讲一个到店理由，不堆产品信息。以下方案是已确认样例，后续新任务可引用本版，五月原记录保持完整。

## 一：早晨带走一杯
标题：出门前，给自己留三分钟。开头写推门、接杯、沿着街区继续走的三个动作。正文介绍方便带走的常规选择，避免承诺出杯速度。拍杯口热气、柜台接杯和门口脚步。结尾：“下次经过，给早晨留个小停顿。”

## 二：午后坐一会儿
标题：今天的这一页，慢慢读。以窗边一本翻开的书开场，描述杯子、光线和安静的停留。拍窗边桌面、书页和杯子细节，不让顾客正脸入镜。结尾提醒座位以到店情况为准，不承诺固定空位。

## 三：第一次怎样点
标题：从你喜欢的味道开始。用清爽、浓郁、不喝咖啡三个方向讲点单，配产品近景与简洁文字卡。结尾：“告诉店员你偏爱的味道，一起选一杯。”
