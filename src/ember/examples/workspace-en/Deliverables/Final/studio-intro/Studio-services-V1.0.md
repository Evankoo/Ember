## How we work together
Qimu Content Studio is a one-person studio made up for this example. It serves small shops and independent businesses, turning scattered ideas into content plans that can be read, shot and checked. Common work includes monthly post planning, event content preparation and service introductions.

## Starting from material
Each collaboration first states this round's goal: who should understand what, and which result is needed. The client provides existing introductions, product information and constraints; the studio records what is confirmed and what still needs checking. For an old project the original plan is found first and this round's new requests are written next, so a past version is never taken as the current decision.

## The delivery process
First a direction and a draft, and the client checks the facts, wording and scope. After confirmation a final file is produced, with a clear content structure and shot suggestions. Revision rounds, amounts of material and delivery dates are agreed before starting; if a new request changes the scope, it is explained again before continuing.

## Suitable work
Suits collaborations with a clear business background that build up content over time, and also a single event or introduction. This example does not include publishing for the client, advertising, store operations or guaranteed results. Names, images and facts used in public still need the client's confirmation.

## Working habits
Each round keeps its inputs, drafts and final deliverables so the next collaboration can continue from the existing background. This file only shows how a final result reads; the services and confirmation are fictional.
