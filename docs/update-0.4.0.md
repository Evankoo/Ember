# v0.4.0：分步初始化与真实安装首任务

## 本次改变

- 初始包包含 `gstudio-init` 1.2.0、`gstudio-core` 1.4.0、`gstudio-project` 1.0.0 三个可直接识别的 Skill 目录，wheel 也包含相同正文与脚本。
- 引导确认目录和安装范围后，建立新用户的 `GStudio` 系统项目，以及真实 `GStudio初始化验收` 首任务。
- 安装选择为有来源、大小和 SHA-256 的输入；技术测试只在隔离工作区执行。结果、失败和验收草稿回到同一任务，不自动正式交付或完成。
- 用户可以在引导中确认第一个真实业务项目；建项 Skill 查重、完整方案确认、受控登记并回读，不猜业务事实或迁移数据。
- 当前初始化文档和设置页同步三项 Skill；底层 `gstudio init` 保留原有空结构语义。

## 首次安装

从 v0.4.0 下载 `gstudio-init-1.2.0.zip`，将三个 Skill 目录交给所用 Agent，调用初始化 Skill。引导空白模式的技术验收结果是一系统 / 一真实安装任务；示例模式为三项目 / 九任务，其中原八项为虚构演示。服务启动和人工验收是随后步骤，不能从安装收据推定完成。

## 已有工作区

此版本不是迁移或重置工具，不自动为已有工作区补建系统和首任务，也不覆盖旧规则、Skill、项目说明或收据。升级程序前备份应用与工作区；采用新契约应作为单独维护范围确认，再逐项核对本地修改。

继续同一目标用原任务；后续独立维护目标使用新卡。旧任务、交付、Git 和发行历史保留；v0.3.0 已退出公开范围的归档中心仍不包含在此版本中。
